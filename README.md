# Lox-go

Golang implementation of the Lox programming language from [Crafting Interpreters book by Robert Nystrom](https://www.craftinginterpreters.com/)

## Installation

1. To install and run locally, clone the repo and build it

```bash
git clone https://github.com/mozarting/lox-go
cd lox-go
go build ./cmd/lox/
```

2. Run example lox programs by using compiled binary

```bash
./lox example.lox
```

3. Or run REPL

```bash
./lox
```
